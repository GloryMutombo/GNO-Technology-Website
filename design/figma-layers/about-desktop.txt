# HOW TO READ THIS FILE
# Each line is one layer. Leading dots = nesting depth (children are indented one more dot).
# Coordinates are in Figma pixels relative to the frame's top-left corner: @x,y WIDTHxHEIGHT
#   G  = group / frame (container). "clip" = clips its content (overflow hidden).
#   R  = rectangle. fill:COLOR[/opacity%]  border:COLOR WIDTH  r:RADIUS
#        fill:img:KEY = image fill (see design/IMAGES.md for KEY -> file). s=scale, t=offset of the image inside the box (object-fit: cover).
#        fill:lin(x1,y1>x2,y2; COLOR@stop ...) = linear gradient (absolute frame coords). rad(...) = radial gradient.
#   T  = text: "content" [layer name if different] FONT SIZE/LINE-HEIGHT wWEIGHT ls:LETTER-SPACING COLOR
#        A "|" inside the text marks where Figma wrapped the line (soft wrap - the browser will re-wrap).
#        A "⏎" marks a hard line break (use <br> or a new paragraph).
#        align:center/right = paragraph alignment (default left).
#        On tablet/mobile files, text written as ="…" is IDENTICAL to the desktop copy (shortened here to save space).
#   I  = icon (Lucide icon name, size, c: color, sw: stroke width).
#   V  = vector shape (lines, dividers, decorative bars).  E = ellipse/circle.  P = path.
#   fx:shadow X Y BLUR SPREAD COLOR = CSS box-shadow: Xpx Ypx BLURpx SPREADpx COLOR.  inset shadow = inner shadow.
#   fx:layerblur N = CSS filter: blur(N/2 px).  bgblur:N = CSS backdrop-filter: blur(N/2 px).  op:N = opacity.
